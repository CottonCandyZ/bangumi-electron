# 离线 fetch 审查与修复（2026-09-05）

审查基线：beta.28（b0f55cc4）。下列 4 项发现已在本分支修复。

## 离线能力边界

已有收藏和章节进度可读、可编辑，修改进入持久队列，联网后再同步。已缓存资源可供页面离线显示。首次登录、未缓存条目、远端搜索和服务器写入仍需要网络；图片尚无完整离线下载保证。完整收藏同步不等于下载整个应用。

## 已修复的问题

1. **单条详情 404 未隐藏旧缓存。** 单条和批量读取现在共用刷新处理：确认 404 后记录账号范围的隐藏标记、清除旧详情数据；临时网络故障保留缓存。清除详情不会递归触发另一次刷新。
2. **资源请求没有全局并发限制。** 单条和批量资源读取共用并发为 1 的队列，按资源、账号版本和 ID 合并进行中或排队的重复请求。单个消费者取消不会影响其他消费者；所有消费者取消后不再启动排队请求，并取消进行中的传输。
3. **后台刷新缺少账号和取消边界。** 移除了独立定时器。SQLite 数据可立即发布，但刷新仍在 Query 的任务中执行。Query AbortSignal 和账号版本共同限制请求、写入和发布；切号再切回也无法复用旧请求。API 获取 token 后再次检查取消状态，避免旧任务继续发送。
4. **IndexedDB 故障阻断 SQLite 内容。** 复用可见性存储实例，并以内存和 localStorage 保存冗余判断。IndexedDB 故障时，确认可见的缓存可继续使用；已隐藏和未知可见性的资源不会被放行。失败的 404 写入仍受冗余标记保护，成功获取资源后才解除隐藏。如果所有持久存储都失败，只有当前会话的判断可以保留，重启后未知资源需要联网确认。

## 首次同步与体验

首次完整同步只能由用户启动。启动、重连、token 更新、单条读取和本地编辑不再自动扫描整个收藏列表；已手动启动的扫描保留暂时故障重试。

收藏操作不再提示“已保存到本地”；评分、私密设置和章节更新不重复弹成功提示。同步冲突由状态入口提示，不主动打断当前页面。

每日放送新增持久化的“只看在追”开关，只读取当前账号收藏状态为“在看”的条目，随收藏失效通知更新。未登录、未完成首次同步和无匹配作品分别显示对应提示。收藏侧栏的初次加载骨架延迟 200ms，快速读取直接进入内容或首次同步引导。
